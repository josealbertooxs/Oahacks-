# Estudio Social

Prototipo web para crear contenido, publicar en Instagram, TikTok y Facebook, y llevar estadísticas de accesos de un antro.

## Cómo abrirlo en VS Code
1. Abre la carpeta `estudio-social` (Archivo > Abrir carpeta).
2. Instala la extensión **Live Server** y haz clic en *Go Live*, o abre `index.html` en el navegador.

## Archivos
- `index.html`: estructura
- `style.css`: estilos
- `script.js`: lógica (registro, borradores, publicación, accesos)

## Notas
- Los datos se guardan en `localStorage` del navegador.
- El login con Google y la conexión a redes están simulados; para producción se necesita backend con OAuth y las APIs de Meta y TikTok.
